# 화면

> [리더보드로](../leaderboard.md)

---

새로 그리는 판이 셋이고, 기존 화면에 더해지는 자리가 셋입니다. **순위는 숫자이고 숫자는
연출이 있어야 무게가 있습니다** — 끝난 판에 `#412` 가 그냥 적혀 있으면 아무 일도 아닙니다.

## 들어가는 자리 셋

|어디|무엇|
|--|--|
|제목 화면|「리더보드」 단추. `ui.button.jokers` 옆. 로그아웃이면 로그인 판을, 로그인이면 리더보드 판을 엽니다|
|제목 화면 오른쪽 위|**내 카드.** 로그인이면 상시로 보이고, 로그아웃이면 아무것도 없습니다. **로그아웃 상태에 「로그인하세요」를 두지 않습니다** — 게임은 혼자 하는 것이고 계정은 권유가 아닙니다. [아래](#내-카드)|
|타이틀 · 시작 오른쪽|**「랭크」 단추.** 로그인이면 보이고 로그아웃이면 없습니다 — 눌러서 로그인 창이 뜨는 것보다, 없는 편이 「게임은 혼자 하는 것」과 어긋나지 않습니다|

## 내 카드

제목 화면 오른쪽 위에 **항상** 있는 작은 판입니다. 게임을 켤 때마다 자기 자리를 봅니다 —
리더보드 판을 열지 않아도 됩니다.

```
┌──────────────────────────────┐
│ ◆ handle_name                │
│   Platinum · 등정 #412       │
│   한 손 최고 #88             │
└──────────────────────────────┘
```

|줄|무엇|
|--|--|
|1|등급 배지와 이름|
|2|등급 이름과 **시즌 `Ascent` 순위.** 등급의 근거인 보드이므로 이것이 첫 줄입니다|
|3|`Main` 탭의 다른 보드 중 **내 순위가 가장 높은 것 하나.** 자랑할 것이 있으면 그것이 보입니다|

순위표에 아직 없으면 2·3줄이 「아직 기록이 없습니다」 한 줄입니다. 값은 부팅할 때 `GET /me`
한 번으로 받고, 런이 끝나 순위가 바뀌면 제목으로 돌아올 때 다시 받습니다.

**누르면 프로필 판이 열립니다.** 카드 자체가 단추입니다.

런 도중에는 카드가 없습니다. HUD 에는 [랭크 표지](#랭크-표지)의 마름모 옆에 등급 배지 하나만 —
런 내내 보이는 것이므로 순위 숫자까지 두면 눈이 갑니다.

## 프로필 판

내 카드를 누르면 열립니다. 순위표에서 다른 사람의 이름을 눌렀을 때 뜨는 것과 **같은 판**이고,
내 것일 때만 아래에 관리 단추가 붙습니다.

|자리|무엇|
|--|--|
|위|등급 배지 크게 · 이름 · 지난 시즌 등급 (있으면)|
|가운데|**보드별 내 순위 전부.** `Main` · `Stake` · `Deck` 탭 순서로, 기록이 있는 보드만. 한 줄이 「보드 이름 · #순위 · 값」이고 누르면 그 보드의 내 자리로 갑니다 (`around=me`)|
|아래 (내 것일 때)|이름 바꾸기 · 로그아웃 · 계정 삭제. 삭제는 이름을 다시 입력받습니다|
|아래 (남의 것일 때)|신고|

**`GET /me` 와 `GET /profiles/{handle}` 이 같은 모양을 돌려줍니다** — 내 것에 관리 단추가
붙는 것 말고는 판이 하나입니다. 판을 둘로 만들면 한쪽만 고쳐지는 날이 옵니다.

## 로그인 판

[options.ts](../../web/src/ui/options.ts) 의 판과 같은 폭 520 입니다.

|자리|무엇|
|--|--|
|위|「리더보드는 계정이 있어야 합니다」 한 줄. **왜 로그인해야 하는지가 먼저입니다**|
|가운데|제공자 단추. 서버의 `/health` 목록과 **빌드의 목록**이 겹치는 것만. GitHub 단추는 `import.meta.env.DEV` 안에 있어 `vite build` 산출물에 없습니다 — [계정](account.md#제공자-4곳)|
|아래|「들고 있는 것: 표시 이름과 제공자의 식별자. 이메일은 받지 않습니다」 작은 글|

단추를 누르면 게임이 제공자로 갑니다. **판이 닫히기 전에 0.3초 어두워집니다** — 갑자기
페이지가 바뀌면 고장으로 보입니다.

## 이름 판

첫 로그인 직후 한 번입니다. 입력 칸 하나와 「이 이름으로」 단추. 서버가 `taken` 을 돌려주면
칸이 붉게 한 번 흔들리고 이유가 아래 한 줄로 적힙니다. **닫을 수 없습니다** — 이름 없는
계정은 순위표에 놓을 자리가 없습니다.

## 리더보드 판

[joker-pool.ts](../../web/src/ui/joker-pool.ts) 의 판이 본입니다 — 격자 · 쪽 넘김 · 오른쪽
설명 자리의 구성이 같습니다.

```
┌──────────────────────────────────────────────────────────────┐
│  [Main] [Stake] [Deck]                     [시즌 ▾] [전체]    │
├──────────────┬───────────────────────────────────────────────┤
│ 등정          │  #    이름            등급   값               │
│ 한 손 최고    │  1    ●●●●            ◆      192              │
│ 최소 핸드 완주│  2    ●●●●            ◆      190              │
│ 완주 소지금   │  …                                           │
│ 완주 횟수     │ ─────── 내 자리 ───────────────────────────  │
│ 건너뛴 블라인드│ 412   나              ▲      118   ← 강조     │
│              │  …                                           │
│ base │ all   │                              ◂ 17 / 40 ▸     │
└──────────────┴───────────────────────────────────────────────┘
```

|자리|무엇|
|--|--|
|위 탭|`BoardGroup` 넷. **시트의 `group` 컬럼이 이 탭입니다.** `Challenge` 탭은 챌린지가 들어온 뒤에 생깁니다 — 보드가 0개인 탭은 그리지 않습니다|
|위 오른쪽|기간. 시즌 이름 또는 「전체」|
|왼쪽 목록|그 탭의 보드. `Stake` 탭은 스테이크 8개, `Deck` 탭은 덱 15개, `Challenge` 탭은 「깬 챌린지 수」와 챌린지 20개. 맨 아래에 풀 전환 — **`Deck` · `Challenge` 탭에는 없습니다**|
|오른쪽 표|한 쪽 25행. 내 행은 항상 강조되고, 내가 이 쪽에 없으면 표의 맨 아래에 내 행이 따로 붙습니다|
|쪽 넘김|`◂ ▸`. 「내 자리로」 단추가 `around=me` 를 부릅니다|

**이름을 누르면 프로필 카드가 뜹니다** — 등급과 보드별 순위. 신고 단추가 여기 있습니다.

### 표의 값

지표마다 적는 법이 다릅니다.

|지표|표기|
|--|--|
|`Ascent`|`금 · 완주` · `보라 · 안테 6 보스`. 숫자 192 를 그대로 적지 않습니다 — 사람이 읽는 것은 스테이크와 자리입니다|
|`BestHand`|`1,284,590`. 천 단위 쉼표. 12자리를 넘으면 `1.28e12` — 지금은 넘지 않습니다|
|`FewestHands`|`31 핸드`|
|`MoneyAtWin`|`$184`|
|`Wins`|`7`|
|`Skips`|`5`|
|`ChallengesBeaten`|`13 / 20`|

### 등급 배지

`Tier.color` 의 작은 마름모. 이름 옆 12px. **등급이 없는 사람(`Ascent` 보드에 없는 사람)은
배지 자리가 비어 있고 칸은 남습니다** — 배지가 있는 줄과 없는 줄의 이름이 어긋나면 표가
울퉁불퉁합니다.

### 챌린지 탭

`Challenge` 탭의 왼쪽 목록은 **깬 것과 못 깬 것과 아무도 못 깬 것 셋으로 갈립니다** —
챌린지 선택 화면의 20칸과 같은 표기입니다.

|상태|목록에서|
|--|--|
|내가 깸|이름 · 내 순위|
|남이 깼고 나는 못 깸|이름 · 1위의 핸드 수|
|아무도 못 깸|이름 · 「아직 아무도」. **누르면 빈 표와 그 한 줄입니다**|

**챌린지 선택 화면에도 같은 줄이 붙습니다.** 20칸마다 「내 기록 · 1위」 한 줄이고, 리더보드 판을
열지 않아도 그 챌린지의 상태가 보입니다. 로그아웃이면 그 줄이 없습니다.

## 랭크 표지

**토글이 아니라 단추 둘입니다.** 「시작」 옆에 「랭크」가 서고, 어느 쪽을 눌렀는지가 그
자체로 이 런이 오르는지를 정합니다 — 토글은 눌러 놓고 잊는 자리가 있고, 단추 둘은 그
자리가 없습니다.

|누른 것|시드|무엇|
|--|--|--|
|시작|미리 깔아 둔 무작위 시드. 옵션에서 고칠 수 있습니다|**오르지 않습니다.** 지금과 같은 길입니다|
|랭크|**서버가 준 것.** 고칠 자리가 없습니다|끝나면 그 보드들에 오릅니다|
|랭크 (로그아웃)|단추가 없습니다|—|

시드를 받지 못하면 시작하지 않고 「지금은 랭크 런을 시작할 수 없습니다」가 뜹니다 — 서버가
없다고 게임을 못 하게 하지 않습니다. 그냥 시작은 그대로 있습니다.

**런 도중에는 표지가 없습니다.** 시작할 때 알림 한 줄이 뜨고 그것으로 끝입니다 — 런 내내
보이는 표지는 그 시간 전부에서 눈에 걸리고, 얻는 것은 이미 아는 사실 하나입니다.

## 런이 끝난 판

지금의 끝난 판(`drawGameOver`) 아래에 한 줄이 늘어납니다. **판정이 오기 전과 뒤가 다릅니다.**

|때|한 줄|
|--|--|
|제출 중|「순위를 세는 중」. 대개 1초 안입니다 — 재현이 끝날 때까지 몇 번 되물어봅니다|
|`accepted` · 순위가 올랐음|**연출.** 아래|
|`accepted` · 순위가 같음|「등정 #412 · 그대로」 조용히|
|`rejected`|「이 런은 순위에 오르지 않았습니다 — <이유>」. 붉지 않습니다. 벌이 아닙니다|
|서버가 없음|「나중에 다시 보냅니다」. `clover.pending` 에 남아 있다는 뜻입니다|
|랭크 런이 아님|아무 줄도 없습니다. **판의 크기까지 지금과 같습니다** — 랭크 런일 때만 두 줄만큼 큽니다|

### 순위가 오른 연출

**순위가 내려가는 숫자입니다.** 예전 순위에서 새 순위로 숫자가 굴러 내려가고, 굴러가는 동안
`coin_land` 를 음높이를 올리며 칩니다 — 득점 연출의 카운터와 같은 규칙입니다. 새 순위에서
멈추면 `blind_clear` 한 번과 작은 `jolt`.

|오른 폭|덧붙는 것|
|--|--|
|한 자리 이하|숫자만|
|한 쪽(25) 이상|`particles.burst` 작게|
|**등급이 바뀜**|배지가 예전 색에서 새 색으로 뒤집히고 `run_win` 이 한 번 더. 판 전체에 `flashScreen` 을 그 등급의 색으로 0.3|
|**처음 순위표에 오름**|「순위표에 올랐습니다」 — 숫자는 굴러 내려갈 예전 값이 없으므로 위에서 떨어져 들어옵니다|

보드가 여럿이므로 오른 것도 여럿일 수 있습니다. **가장 많이 오른 하나만 연출하고** 나머지는
아래에 작은 글로 「한 손 최고 #88 ↑12 · 완주 횟수 #301 ↑1」. 하나씩 다 연출하면 끝난 판이
30초가 됩니다.

## 6개 언어

`ui.lb.*` 열쇠 40개 안팎이 `StringTable` 에 더해집니다. 보드 이름은 `leaderboard.<id>.name`,
등급 이름은 `tier.<id>.name` — 표의 `name` 칸과 같은 규약입니다.

**독일어가 가장 깁니다.** 표의 이름 칸이 영문 16자로 고정이므로 문제는 왼쪽 목록입니다 —
「Wenigste Hände bis zum Sieg」가 「최소 핸드 완주」의 두 배입니다. 목록의 폭을 가장 긴 언어로
맞추지 않고 **넘치면 두 줄로 내립니다** — `rich.ts` 의 `maxWidth` 가 이미 그렇게 합니다. 글자를
줄이는 헬퍼는 없고 만들지 않습니다.
