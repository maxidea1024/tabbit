# `data/` — 격자

`.tsv` 하나가 **시트 하나의 격자 그대로**입니다. 저작기(`tools/Authoring`)의 역할은 이
격자에 서식을 얹어 `.xlsx` 로 쓰는 것뿐이고, 값을 계산하거나 컬럼을 만들지 않습니다.

## 형식

첫 열이 **마커 열**이고, 나머지가 그 엔티티의 컬럼입니다.

```
:table Joker(key=joker_id)	조커 한 종입니다.
:field	joker_id	rarity	cost	name
:type	string	Rarity	int (min=1, max=10)	string (text=Joker)
:desc	식별자	희귀도	상점에서의 값	표시 이름
	twig	Common	2	둥근 잔가지
```

|줄|내용|
|--|--|
|`:table …` · `:const …`|**선언 셀 하나**입니다 — 키워드와 이름을 한 칸에 적고, 오른쪽 칸이 설명입니다|
|`:field` · `:type` · `:desc`|헤더 행|
|첫 칸이 빈 줄|데이터 행|

**선언된 옵셔널 컬럼의 빈 값은 `-` 입니다.** 빈 칸은 「적는 것을 잊었다」와 구분되지 않으므로
이 도구가 값을 요구합니다. 다형 변종의 멤버 컬럼은 다릅니다 — 그 행의 변종이 가지지 않는
멤버는 빈 칸입니다.

## 효과 격자 8개

`JokerEffect` · `TarotEffect` · `SpectralEffect` · `BossEffect` · `VoucherEffect` ·
`TagEffect` · `DeckEffect` · `EnhancementEffect` · `SealEffect` 가 **같은 컬럼 구성**입니다.
다른 것은 `owner` 가 무엇을 가리키는가뿐입니다.

컬럼이 60개 남짓인 것은 변종의 멤버가 모두 나란히 놓이기 때문입니다. 한 행이 쓰는 것은
그중 서넛이고 나머지는 빈 칸입니다 — **그것이 다형 컬럼의 모양입니다.**

## 시드와 그 이후

`tools/seed.py` 가 이 파일들을 **처음 한 번** 만들었습니다. 조커 150종의 효과를 손으로
적으면 어긋나고, 대조표에서 옮겨야 하기 때문입니다.

**그 이후의 수정은 `.tsv` 에서 합니다.** `seed.py` 를 다시 돌리면 손으로 고친 값이
사라지므로, 값을 다시 계산해야 하는 경우와 컬럼 구성을 바꾸는 경우에만 씁니다.
어느 쪽이 정본인지가 갈리지 않도록 여기 적어 둡니다 — **정본은 `.tsv` 입니다.**
