# 소리 38개 — 가져온 것

**자작이 아닙니다.** 트럼프 52장의 얼굴과 같은 예외이고, 같은 이유입니다.

|무엇|값|
|--|--|
|출처|[Kenney](https://kenney.nl) 의 `casino-audio` 와 `interface-sounds`|
|라이선스|[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) — 공유 재산. 표기 의무가 없습니다|
|받은 날|2026-08-31|
|손댄 것|없습니다. 신호의 이름으로 바꿔 놓은 것뿐입니다|

## 예외를 둔 이유

**합성으로는 되지 않습니다.** 오실레이터 하나와 잡음으로 만든 「탁」 은 어떤 값을 주어도
전자음이고, 종이가 스치는 소리나 칩이 부딪히는 소리로 들리지 않습니다 — 그 둘은 물리적으로
복잡해서, 손으로 다듬는 것보다 녹음된 것을 가져오는 편이 낫습니다.

CC0 을 고른 것도 이유가 있습니다. 표기 의무가 있는 것을 쓰면 **누구의 어느 파일인지를 38개
따라다녀야** 하고, 그 목록은 언젠가 실제와 어긋납니다.

## 파일의 이름

**파일 이름이 곧 신호의 이름입니다.** `SoundCue` 표의 `cue_id` 와 같고, 그래서 어느 파일이
어느 소리인지 다른 곳을 보지 않아도 됩니다.

가져오는 것은 [`design-data/tools/sound.py`](../../../design-data/tools/sound.py) 입니다 —
어느 꾸러미의 어느 파일이 어느 신호가 되었는지가 그 안의 지도 하나에 있습니다.

```
python samples/clover/design-data/tools/sound.py --fetch
```

## 크기

**읽을 때 스스로 맞춥니다.** 꾸러미의 파일은 저마다 음량이 달라서 — 카드가 스치는 소리는
작고 확인음은 큽니다 — 그대로 두면 어떤 신호는 들리지 않고 어떤 신호는 귀를 찌릅니다.
`audio.ts` 가 앞 0.4초의 실효값을 재서 한 크기로 맞추고, **뜻으로 키우거나 줄이는 것만**
`SoundCue.gain` 에 둡니다.

## 없을 때

파일이 없거나 읽지 못하면 합성으로 갑니다. 소리가 아예 안 나는 것보다는 전자음이라도 나는
편이 낫고, 그래서 `audio.ts` 의 파형 표는 걷어내지 않았습니다.
