# 아이콘

**가져온 것입니다.** [Lucide](https://lucide.dev) 의 것이고 라이선스는 ISC 입니다 —
저작권 표시를 그대로 남기면 쓰고 고치고 나눌 수 있습니다.

|파일|Lucide 의 이름|쓰는 자리|
|--|--|--|
|`circle-question-mark.svg`|`circle-question-mark`|타이틀의 「게임 방법」|
|`settings.svg`|`settings`|타이틀의 「옵션」|

한 곳만 고쳤습니다 — `stroke="currentColor"` 를 `#ffffff` 로 바꿨습니다. **`currentColor`
는 그림으로 구울 때 풀리지 않습니다**: CSS 의 글자색을 가리키는 말이고 캔버스에는 그런 것이
없어서, 그대로 구우면 선이 검게 나오거나 아예 없습니다. 흰색으로 구워 두고 화면에서 물을
들입니다 — 색을 곱하는 것이므로 흰 것에만 제대로 걸립니다.
