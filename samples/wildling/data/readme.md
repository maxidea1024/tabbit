# `data/` — 밸런스 값

`.tsv` 하나가 **시트 하나의 격자 그대로**입니다. 저작기(`tools/`)가 하는 일은 이 격자에 서식을
얹어 `.xlsx`로 쓰는 것뿐이고, 값을 계산하거나 컬럼을 만들지 않습니다.

## 형식

첫 열이 **마커 열**이고, 나머지가 그 엔티티의 컬럼입니다.

```
:table	Monster(key=monster_id)	종의 한 단계입니다.
:field	monster_id	stage	name
:type	string	int (min=1, max=3)	string (text=Monster)
:desc	식별자	각성 단계	표시 이름
:target	c,s	c,s	c
	sprout_deer_1	1	새싹사슴
```

|줄|내용|
|--|--|
|`:table` · `:enum` · `:const`|선언 셀. 오른쪽 칸이 설명입니다|
|`:field` · `:type` · `:desc` · `:target` · `:variant`|헤더 행. 순서는 자유이고 `:field`만 필수입니다|
|첫 칸이 빈 줄|데이터 행|
|첫 칸이 `#`인 줄|그 행을 변환에서 제외|

**멀티 로우의 연장 행은 기본 인덱스 칸이 빈 데이터 행**입니다. 그 격자를 그대로 적습니다.

`Const_*.tsv`처럼 한 파일에 엔티티가 둘 이상인 것은 `:table`/`:const` 줄이 여러 번 나타나고,
완전히 빈 줄이 그 사이의 경계입니다.

## 시드와 그 이후

`tools/seed.py`가 이 파일들을 **처음 한 번** 만들었습니다. 능력치 곡선처럼 산식으로 정하는 값이
많아 손으로 적으면 어긋나기 때문입니다.

**그 이후의 수정은 `.tsv`에서 합니다.** `seed.py`를 다시 돌리면 손으로 고친 값이 사라지므로,
값을 다시 계산해야 하는 경우에만 씁니다. 어느 쪽이 정본인지가 갈리지 않도록 이 문서에
적어 둡니다 — **정본은 `.tsv`입니다.**
