파생본이 필요하면 스크립트에 규칙을 더합니다.

## 파생본

```
node build-assets.mjs
```

`dist/`에 만들고, 사이트가 읽는 것은 `website/static/img/`로 함께 복사합니다.
**`dist/`는 커밋합니다** — `.csproj`가 실행 파일 아이콘으로 참조하므로, 커밋하지 않으면
.NET 빌드에 Node가 필요해집니다.

|파생본|출처|쓰는 곳|
|--|--|--|
|`icons/favicon.ico` · `favicon-{16…512}.png`|`lockup-sheet`의 두 번째 변형(보라 타일)|문서 사이트, [history.html](../src/History/web/history.html)|
|`icons/tabbit.ico` (16~256)|「앱 아이콘용」 그림|**실행 파일 아이콘** — `src/Tabbit.csproj`의 `ApplicationIcon`|
|`icons/app-{16…256}.png`|같음|아이콘 미리보기·다른 플랫폼용|
|`banner.png`|`brand-sheet`의 왼쪽 패널|랜딩 히어로|
|`og-card.png` 1200×630|배너|링크 공유 카드|
|`readme-header.jpg`|배너|저장소 첫 화면|
|`mark.png` · `wordmark.png` · `logo-horizontal-light.png`|`lockup-sheet` 하단|배경을 뺀 조합용|
|`icons/<변형>.png` 6종|`lockup-sheet` 가운데 줄|상태 표시 등|

좌표는 눈으로 재지 않았습니다. `inspect.mjs`가 흰 배경 위의 패널 경계를 찾아 준 값입니다.

```
node inspect.mjs source/brand-sheet.png          # 전체
node inspect.mjs source/lockup-sheet.png 0 901 1253 1089   # 영역을 좁혀서
```

### 알아둘 것 둘

**흰 배경은 임계값으로 지우지 않습니다.** 밝기만 보면 흰 토끼에 구멍이 뚫립니다. 가장자리에서
시작해 흰색을 따라 들어가는 방식이라 어두운 외곽선 안쪽은 남습니다.

**가로 락업의 워드마크는 밝은 바탕 전용입니다.** 검은 글자라 브랜드 배경에 얹으면 읽히지 않고,
글자 안쪽의 흰 구멍이 얼룩으로 보입니다. 그래서 소셜 카드와 readme 헤더는 그것으로 만들지 않고
**배너를 씁니다** — 배너는 이미 브랜드 배경 위에 완성된 구성입니다.

## 알려진 것

**워드마크 서체가 장마다 미세하게 다릅니다** — `T`의 귀 간격과 `i` 점의 위치. 래스터로 쓰는
동안은 상관없지만, 벡터 워드마크가 필요해지면 **한 장을 정본으로 정해 SVG로 다시 그리는 작업**이
한 번 필요합니다.
