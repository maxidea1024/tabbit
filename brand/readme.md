## 파생본

```
node build-assets.mjs
```

`dist/`에 만들고, 사이트가 읽는 것은 `website/static/img/`로 함께 복사합니다.
**`dist/`는 커밋합니다** — `.csproj`가 실행 파일 아이콘으로 참조하므로, 커밋하지 않으면
.NET 빌드에 Node가 필요해집니다.

|파생본|출처|쓰는 곳|
|--|--|--|
|`icons/favicon.ico` · `favicon-{16…512}.png`|`lockup-sheet`의 두 번째 변형(보라 타일)|문서 사이트, [history.html](../src/History/web/history.html)|
|`icons/tabbit.ico` (16~256)|「앱 아이콘용」 그림|**실행 파일 아이콘** — `src/Tabbit.csproj`의 `ApplicationIcon`|

좌표는 눈으로 재지 않았습니다. `inspect.mjs`가 흰 배경 위의 패널 경계를 찾아 준 값입니다.

```
node inspect.mjs source/lockup-sheet.png 0 901 1253 1089   # 영역을 좁혀서
```

### 배너에서 지우는 것

원본 배너 하단에는 `TCB — Tabbit Binary | Fast. Compact. Reliable.` 알약이 그려져 있습니다.
**두 가지가 틀렸습니다** — TCB는 **Tabbit Compiled Binary**이고, 파일 형식의 약자는 브랜드
이미지가 말할 것이 아니라 문서가 말할 것입니다. 그래서 파생 단계에서 지웁니다.

문자열이 아니라 그림이라 지우는 데 두 단계가 듭니다. 배경이 세로 그라디언트여서 단색으로
칠하면 띠가 보이므로 **알약 위아래 행을 컬럼마다 보간해서** 채우고, 그러면 알약이 앉아 있던
라벤더 띠가 빈 여백으로 남으므로 **평평한 부분만 잘라냅니다** — 컨테이너의 둥근 아래 모서리는
남기고, 이어붙인 자리는 다시 보간해 지웁니다. 결과는 784px에서 748px입니다.

원본은 그대로 둡니다. 시안을 다시 뽑으면 이 단계는 지우면 됩니다.

### 알아둘 것 둘

**흰 배경은 임계값으로 지우지 않습니다.** 밝기만 보면 흰 토끼에 구멍이 뚫립니다. 가장자리에서
시작해 흰색을 따라 들어가는 방식이라 어두운 외곽선 안쪽은 남습니다.

**가로 락업의 워드마크는 밝은 바탕 전용입니다.** 검은 글자라 브랜드 배경에 얹으면 읽히지 않고,
글자 안쪽의 흰 구멍이 얼룩으로 보입니다. 그래서 소셜 카드와 readme 헤더는 그것으로 만들지 않고
**배너를 씁니다** — 배너는 이미 브랜드 배경 위에 완성된 구성입니다.

### 일하는 GIF

```
node build-working-gif.mjs            # dist/tabbit-working.gif
```

`mascot-working.png` 한 장으로 256×256 GIF 16프레임을 굽습니다. 프레임마다 다른 그림을 만드는
것이 아니라, **한 장에서 움직일 것만 골라 옮깁니다.**

|움직이는 것|어떻게|
|--|--|
|앞발|**발 모양 타원으로 오려** 번갈아 4px 들어 올립니다. 사각형째로 옮기면 소맷단에 계단이 생깁니다. 발이 비운 자리는 바로 아래 시트를 늘려 덮습니다|
|들어오는 시트·나가는 큐브·반짝이·진행 막대|스크립트가 SVG로 그려 얹습니다. 큐브 3색은 이 도구의 세 산출 그대로입니다|

**카메라는 고정입니다.** 흔들면 배경이 프레임마다 달라져 GIF가 세 배로 커집니다 — 고정하면
110KB, 1% 줌만 넣어도 300KB입니다.

## 알려진 것

**워드마크 서체가 장마다 미세하게 다릅니다** — `T`의 귀 간격과 `i` 점의 위치. 래스터로 쓰는
동안은 상관없지만, 벡터 워드마크가 필요해지면 **한 장을 정본으로 정해 SVG로 다시 그리는 작업**이
한 번 필요합니다.

**`mabbit`의 워드마크는 첫 글자가 아직 계열을 따르지 않습니다.** `tabbit`의 `T`는 보라색이고
귀가 달려 있는데, `mabbit`의 `m`은 흰색이고 귀가 없습니다. 생성으로 3번 시도해 철자·배경·배지·
시트 수렴은 맞췄고 이 하나가 남았습니다. **위의 벡터 워드마크 작업과 같은 자리**이므로, 그때
`T`와 `m`을 함께 그리는 편이 낫습니다.
