## 입력

- **엑셀과 구글 스프레드시트를 둘 다 씁니다.** 팀이 편한 쪽으로 고르면 되고, 한 프로젝트에서 섞어 써도 결국 하나로 합쳐집니다.
- **이 도구의 규칙으로 쓰이지 않은 시트도 읽습니다.** 레이아웃을 소스 항목마다 지정하므로 한 번에 섞어 읽을 수 있습니다 — [시트에 무엇을 적을 수 있나](concepts.md#다른-규칙으로-쓰인-시트-읽기).
- **서버와 클라이언트 중 한쪽에만 필요한 테이블과 컬럼은 그쪽 빌드에만** 넣을 수 있습니다 (`TargetSide`).
- 워크북을 객체 모델로 펼치지 않고 **스트리밍으로 읽습니다.** 349시트를 읽는 실행의 peak이 7.4 GB에서 2,757 MB가 되었습니다 — [설계와 실측](../spec/streaming-workbook-reader.md).

## 시트가 담을 수 있는 것

- **컬럼 여러 개를 레코드 하나로 접습니다** — `Group.Member` 표기. 깊이에 상한이 없어 멤버가 다시 레코드여도, 배열이어도 됩니다 ([중첩 필드](../spec/nested-fields.md) · [다중 중첩](../spec/nested-multi-level.md)).
- **벡터 · 회전 · 색을 셀 하나에** 적습니다 — `(1,2,3)` · `#3366CC` · `red` ([아래](sheets.md#합성-값-타입--벡터--회전--색)).
- **플래그 묶음은 `bitset`** 하나로 받습니다. 진법 리터럴을 쓰고, 빈 칸은 오류입니다 ([아래](sheets.md#bitset--플래그-묶음)).
- **번역 대상 문자열은 `text`**로 표시하면 그룹마다 파일 하나로 수집됩니다. 값은 `string` 그대로라 **내보낸 바이트가 움직이지 않습니다** ([아래](sheets.md#text--번역을-위해-수집되는-문자열)).
- **애셋 이름은 `asset`**으로 표시하면 그 이름의 파일이 있는지 확인하고, 없으면 **어느 셀인지** 함께 보고합니다 ([아래](sheets.md#asset--파일이-있어야-하는-문자열)).
- **컬럼 이름이 행 id인 격자**(매트릭스 표)를 읽습니다 — 값은 배열 하나로, 컬럼 id는 옆 테이블로 나옵니다 ([설계](../spec/matrix-tables.md)).
- **한 테이블에 데이터를 여러 벌** 둘 수 있습니다(지역 변종 등). 타입은 하나이고, 벌을 가르는 표기는 recipe가 적습니다 ([설계](../spec/table-row-sets.md)).
- **같은 레코드 타입을 테이블마다 다시 적지 않아도 됩니다** — 임베딩 오브젝트와 enum을 시트 밖의 `.tbs` 파일에 선언합니다 ([설계](../notes/struct-dsl-design.md)).

## 검증

- **변환하면서 걸러낼 수 있는 실수는 최대한 걸러냅니다.** 게임에서 문제가 생긴 뒤에 찾는 대신 변환할 때 알게 됩니다.
- **문제가 생기면 어느 셀인지 보고합니다.** 구글 시트라면 링크를 눌러 그 자리로 바로 갑니다.
- **시트의 문제를 한 번에 모아서 보고합니다.** 하나 고치고 다시 돌리기를 반복하지 않아도 됩니다.
- **타입으로 나타낼 수 없는 것도 시트에서 읽습니다** — 범위·허용값·필수 여부 ([컬럼 제약](../spec/column-constraints.md)).
- **찾은 것을 로그가 아니라 보고서로 냅니다.** 실행이 끝나면 HTML 한 장과 JSON 한 장이 남고, 경고 이상이면 브라우저가 열립니다. 구글 시트의 셀은 클릭 한 번이고, 직전 실행과 대조해 **신규 · 지속 · 해소**를 셉니다 ([사용](cli.md#빌드-리포트--찾은-것을-고칠-사람에게) · [설계](../spec/build-report.md)).
- **지금 고칠 수 없는 문제는 적어 두고 넘어갑니다.** recipe에 자리와 이유를 적으면 보고는 `Info`로 남고 실행이 멈추지 않습니다. **건수가 달라지거나 아무것도 맞추지 못한 항목은 오류입니다** ([설계](../spec/known-problems.md)).
- **시트로도 나타낼 수 없는 규칙은 C#으로 적습니다.** 프로젝트의 `.cs` 파일을 변환할 때 컴파일해 돌리고, 게이트는 모든 타깃보다 앞이라 실패한 실행이 파일에도 데이터베이스에도 흔적을 남기지 않습니다 — [검증](validation.md).

## 산출

- **여러 언어로 뽑을 수 있습니다.** C#(**.NET과 유니티 모두**), TypeScript, C++, C, Go, Rust, Python, Java, Kotlin, Swift, Lua, Ruby, PHP, Dart 코드와 언리얼 모듈 — [언어별 가이드](languages/readme.md).
- **테이블끼리 참조할 수 있습니다.** 같은 값을 여러 시트에 옮겨 적지 않아도 됩니다. 참조는 파일에 인덱스로 저장되고, 로드 후 실제 레코드 참조로 연결됩니다.
- 파일(바이너리·JSON) 말고 **MySQL / PostgreSQL / MongoDB / Redis에 바로 적재**할 수도 있습니다 — [내보내기](exports.md).
- **컬럼마다 그 값들에 가장 짧은 인코딩을 고릅니다** — 사전·RLE·델타·비트폭 패킹 ([바이너리 형식](binary-format.md#컬럼-인코딩)).
- **실제로 로드된 데이터를 HTML로 펼쳐 볼 수 있습니다.** 값이 제대로 들어갔는지 눈으로 확인하고 넘어갈 수 있습니다.
- **따로 설치할 것이 없습니다.** 바이너리를 읽는 코드까지 출력 폴더에 같이 나오므로 플러그인을 깔거나 include 경로를 잡을 일이 없습니다. Go는 `go.mod`, Rust는 `Cargo.toml`, 언리얼은 `Build.cs`까지 함께 나옵니다.
- **데이터만 따로 패치**할 수 있습니다. 익스포트 결과를 CDN에 올려두면 생성된 업데이터가 바뀐 파일만 받아 최신으로 유지합니다 — 해시로 검증하고, 일시적인 장애는 재시도하고, 실패하면 이전 데이터를 그대로 둡니다 (`WriteUpdater`).

## 실행

- **바뀐 것이 없으면 아무것도 하지 않습니다.** 지난 실행이 무엇을 읽고 무엇을 썼는지 기록해 두었다가 비교하고, 전체를 다시 하게 되면 **그 이유를 함께 출력합니다** ([사용](cli.md#다시-하지-않기--빌드-캐시) · [설계](../spec/build-cache.md)).
- **검증까지만 돌리고 산출물을 만들지 않는 실행**이 있습니다(`--validate-only`) — PR 검사가 쓰는 것입니다.
- **도구가 내는 메시지는 영어 · 한국어 · 중국어 간체 · 중국어 번체 · 일본어**입니다. 메시지마다 ID가 있어 CI가 종류로 거를 수 있습니다 ([설계](../spec/message-ids.md)).

## 안전

- **변환이 중간에 실패해도 이전 결과는 그대로 남습니다.** 파일은 스테이징 영역에 모았다가 마지막에 한꺼번에 옮기고, 데이터베이스는 섀도 테이블에 채운 뒤 통째로 바꿉니다.
- **읽는 쪽도 마찬가지입니다.** 이미 로드된 테이블을 다시 읽어도(데이터 패치·핫 리로드) 전부 읽고 참조까지 연결한 다음에 한 번에 교체합니다. 중간에 실패하면 **이전 데이터가 그대로 남고** 이유를 알려줍니다 — 빈 테이블이나 반쯤 채워진 테이블로 남는 일이 없습니다.
- **스키마가 바뀌어도 감지되지 않는 읽기 오류가 되지 않습니다.** 읽을 수 있으면 정확히 읽고, 읽을 수 없으면 필드 이름과 양쪽 타입을 대고 멈춥니다 — [바이너리 형식](binary-format.md).
- **변조를 검출합니다.** 파일 시그니처와 MAC이고 모든 런타임이 지원합니다 — [설계](../spec/tcb-mac-and-signature.md).

> 원자성은 **저장소 하나 단위**입니다. 파일 여러 개와 데이터베이스 여러 개를 한 트랜잭션으로 묶는
> 건 분산 트랜잭션 없이는 안 되므로, 각각이 따로 안전하게 바뀌도록 만들어져 있습니다.

## 추적

- **누가 언제 무엇을 바꿨는지 셀 단위로 남고**, 웹 브라우저에서 볼 수 있습니다 (`--serve`) — [Summary와 히스토리](history.md).
- 히스토리가 커밋마다 **데이터 패치와 코드 배포 중 무엇이 나가야 하는지 판정**합니다. 상수만 고쳐 데이터를 올리는 헛배포, enum 값이 밀린 채 코드만 나가는 사고를 배포 전에 보고합니다.
